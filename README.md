# 바로붕 (Baroboong) — 빠른 즐겨찾기 앱

링크를 복사해 두면 앱을 열 때 바로 감지해서 자동 등록을 제안하는, 휴대폰용 빠른 즐겨찾기 앱입니다.

## 기능

- **자동 등록**: 링크 붙여넣기 한 번으로 제목과 핵심 요약을 자동으로 가져와 요약 박스로 저장, 복사해 둔 링크가 있으면 앱을 열거나 다시 돌아올 때 '바로 저장하기' 배너 표시
- **날짜·분류별 정리**: 오늘 / 어제 / 이번 주 / 이전으로 묶어 보여주고, 분류(업무·공부·뉴스·영상 등)와 주제 태그를 답니다
- **검색**: 주제·내용·태그로 찾기, 분류 필터
- **공유 / 수정 / 삭제**: 각 카드에서 열기·공유·수정·삭제
- **모바일 UI**: 한 손으로 쓰기 편한 휴대폰 화면 전용 디자인

## 구조

- `client/` — React + TypeScript 프론트엔드 (모바일 UI)
- `server/` — 북마크 저장/조회/검색 액션과 DB 스키마
- `drizzle/` — DB 마이그레이션 SQL

## 참고

이 저장소는 Muse 웹 앱(아티팩트)으로 만든 바로붕의 소스 스냅샷입니다. `package.json`의 `@hatch/space-sdk` 의존성은 Muse 런타임을 가리키므로, Muse 밖에서 그대로 실행하려면 해당 SDK 부분을 일반 서버 코드로 교체해야 합니다.
